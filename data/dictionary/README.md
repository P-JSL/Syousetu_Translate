# Embedded Japanese–Korean core glossary

`ja-ko-core.tsv` is a project-authored glossary of common everyday and fiction
vocabulary with Korean representative dictionary glosses. These are independently
written word facts, not translations generated by SMaLL-100 or an imported binary
dictionary. Review the UTF-8 TSV directly; regenerate the bounded Deflate asset
with `cargo run --locked --no-default-features --example pack_dictionary`.

The application uses **exact-source matching** for these headwords. A noun or
verb dictionary form is not substituted into an arbitrary sentence, conjugation
or substring: Japanese words can have multiple senses, and Korean grammar needs
sentence context. Sentences continue through the neural model. Existing user
corrections take precedence, and deleted defaults stay deleted after persistence.
`--no-learning` disables these defaults for controlled inference comparisons.

Data is provided under this repository's MIT license. Default sentence examples
and source-qualified spelling rules are maintained separately in `data/learning/`.
