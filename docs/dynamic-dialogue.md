# 원문과 번역문을 대조하는 한국어 대사 보정

일본어 문장의 인용 범위와 한국어 결과의 문장 경계를 대조해 말투와
발화 의도를 해당 위치에 적용한다. 내부 SMaLL-100 INT8 번역과 공통 자연어
처리를 사용하는 호환 경로가 같은 Rust 후처리를 사용한다. 직접 지정한
교정 문장과 사전은 각 경로의 기존 우선순위를 따른다.

## 판단 기준

- 대사 안의 문장 수와 질문 경계, 숫자 표기가 대응하면 문장마다 말투를
  판단한다. 원문의 대사 두 문장이 쉼표로 합쳐진 경우에는 명시적인 말투
  변화와 양쪽 한국어 서술어를 확인한 뒤 마침표를 복원한다. 질문표가 빠진
  `大丈夫？`는 해당 한국어 서술어가 확인되면 질문으로 되돌린다.
- 서술 속 인용은 원문과 결과에 각각 하나의 균형 잡힌 직접 인용이 있을 때
  그 안의 말투만 보정한다. 음성을 전달하는 직접 인용에 맞춰 필요한 경우
  연결 조사도 정리한다. 문장 대응이 모호할 때 원문 전체의 말투가 일관되면
  공통 종결형을 적용한다. 중첩 인용과 서로 다른 말투가 섞인 문장은
  원문의 문장부호를 바탕으로 표시만 정리한다.
- 허용, 선택, 의무, 금지의 구별은 확인된 일본어 종결형과 한국어의 같은
  동작이 모두 있을 때 적용한다. 행동 앞의 대상·시간 표현을 보존하며,
  `無理に`가 명시된 선택 표현에서는 누락된 강요 범위를 함께 복원한다.
  반어, 이중 부정의 원문, 다른 서술어가 나온 경우에는 뜻을 추측하기보다
  원래 생성된 표현을 사용한다.

## 실제 고정 모델 비교

비교는 `v0.3.8`과 수정 코드에서 같은 SMaLL-100 INT8 모델로 진행했다.
교정 기억과 결과 재사용을 끄고, 새로 작성한 46문장과 기존 검토 128문장의
모든 변경 결과를 읽어 비교했다. 새 사례 20문장이 달라졌다. 기존 사례는
`大丈夫？`의 질문표를 복원한 1문장만 달라졌다.
[새 검토 문장](../tests/fixtures/dynamic_dialogue_ja.txt) ·
[기존 검토 문장](../tests/fixtures/natural_language_review_ja.txt)

| 일본어 원문 | 기존 결과 | 보정 결과 |
| --- | --- | --- |
| `「今は大丈夫です。次は私がやるよ。」` | 그럼 지금 괜찮아, 다음엔 내가 할 거야. | 그럼 지금 괜찮아요. 다음엔 내가 할 거야. |
| `「今日はその本を読まなくてもいいよ。」` | 오늘은 그 책을 읽어서는 안 돼. | 오늘은 그 책을 읽지 않아도 돼. |
| `「この水を飲まなきゃだめです。」` | 이 물을 마셔야 하지 않아. | 이 물을 마셔야 해요. |
| `「今日は無理に食べなくてもいいですよ。」` | 오늘은 먹을 수 없어. | 오늘은 무리해서 먹지 않아도 돼요. |

개별 어휘와 화자 관계에는 모델의 오역이 남는다. 인용 안의 선택 표현이
교정된 사례에도 서술의 `兄`가 “형제”로 생성된 부분이 있다. 위 건수는
출력의 변경 범위를 나타낸다.

## 임시 할당 감소

후처리에서는 한 번 분석한 인용 범위를 재사용하고, 변경이 없는 문자열은
빌려 읽는다. 평문과 CRLF 처리는 문자열 목록을 만들지 않고 출력에 이어
쓴다. 축약형은 매칭 결과를 한 번 순회해 정적 규칙을 적용하고, 디코딩된
문자열의 공백은 기존 버퍼에서 정리한다. 긴 입력의 분할 위치를 계산할
때는 문자 인덱스의 전체 배열을 만들지 않는다.

기존 결과에서 두 후처리가 같은 출력을 낸 127개를 대상으로, 초기화가 끝난
후 Rust 할당기에서 할당·재할당 호출을 세었다. 1,030회에서 426회로
줄었다. 같은 출력이 확인된 새 사례 46개의 축약형 처리에서 임시 요청
바이트 합계는 6,652에서 1,420바이트로 줄었다. 이 값은 해당 처리의
할당 계측이며 모델 추론 전체의 메모리나 시간은 별도로 측정한다.

## 전체 작품 저장

같은 INT8 모델로 35화와 24화 전체를 번역하고 원문 줄·빈 문단·회차 순서와
번역 누락을 별도 검증기로 검사했다. 두 작업의 각 저장 줄에서 ASCII 숫자를
추출해 v0.3.8 대조 파일과 순서대로 비교했으며 불일치는 0개였다.

| 작품 | 원문 줄 수 | 저장 검증 | v0.3.8과 달라진 TXT 줄 |
| --- | ---: | --- | ---: |
| 35화 | 6,248 | 전체 통과 | 399 |
| 24화 | 17,041 | 전체 통과 | 104 |

달라진 줄에는 문장 사이 공백과 종결형 정리도 포함된다. 별도의 실제
모델 회귀 시험에서 새 검토 사례의 순차·배치 결과가 같음을 확인했다.
