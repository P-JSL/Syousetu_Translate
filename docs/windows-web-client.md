# 웹소설 번역기 (Rust)

`translator7.zip`의 웹소설 실행 흐름을 Rust로 옮긴 프로그램입니다.
Java·JavaFX·JRE 설치는 필요하지 않습니다.

## 실행

1. `syousetu-gui.exe`, `syousetu-translate.exe`, `웹소설 번역기.bat`을
   같은 폴더에 두고 BAT 파일을 실행합니다.
2. **설정 → ezTrans 폴더 선택**에서 기존에 사용하던 ezTrans의 최상위
   폴더를 선택합니다. 이 폴더에는 `J2KEngineH.dll` 또는 `J2KEngine.dll`,
   `J2KEngine.dlx`, `Dat` 폴더가 있어야 합니다. 설정을 저장합니다.
3. **웹소설** 탭에서 작품 URL을 입력합니다. 필요한 경우 **목차 확인**으로
   작품과 화수를 확인하고 시작·마지막 화를 지정합니다. 마지막 화의 `0`은
   끝까지 받는다는 뜻입니다.
4. **번역 실행**을 누릅니다. 출력 파일을 미리 지정하지 않았다면 저장 위치
   선택 창이 열립니다. 파일명 자동 생성을 켜면 작품 제목으로 저장합니다.
5. 작업 큐에서 진행률과 완료·실패 상태를 확인합니다. 대기 중인 작업은
   순서를 바꾸거나 목록에서 삭제할 수 있습니다.

설정의 `eztrans`는 기존 엔진으로 번역하며, `passthrough`는 번역 없이
일본어 원문을 저장합니다. 사용자 사전은 기본적으로
`config/dictionary.txt`를 읽고 다른 사전 파일도 지정할 수 있습니다.
이미 추가한 작업에는 추가 당시의 설정이 유지됩니다.

## 필요한 파일

Windows x86 실행 파일을 사용해야 기존 32비트 번역 DLL을 불러올 수 있습니다.
ezTrans XP 전체 프로그램을 복사할 필요는 없지만, **기존 번역 DLL과 그
데이터·의존 파일은 필요합니다.** 이 배포물에는 해당 파일이 들어 있지
않습니다. 기존 설치 폴더를 그대로 지정하시면 됩니다.

지원 사이트는 Kakuyomu, Alphapolis, Syosetu, Syosetu18, Hameln,
Novelup입니다. 접근이 제한된 페이지나 지원되지 않는 페이지 형식은
작업 로그에 오류가 표시됩니다.
