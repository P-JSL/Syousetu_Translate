# 웹소설 번역기 0.3.1 (Windows x64)

일본어→한국어를 직접 번역하는 Rust 내부 오프라인 모델을 사용합니다.
Windows 10/11 x64에서 실행하며 Java·Python·GPU·ezTrans XP 설치가 필요하지 않습니다.

## 실행

기본 다운로드 폴더는 `C:\Users\rabbit\OneDrive\문서`입니다. 설정의 다운로드
기본 폴더, 직접 지정한 출력 파일 또는 CLI의 `--output-dir`로 변경할 수 있습니다.

1. ZIP 전체를 같은 폴더에 풀고 **웹소설 번역기.bat**을 실행합니다.
2. ZIP에 **SMaLL-100 INT8 모델·설정·토크나이저가 포함**되어 있습니다.
   실행 파일 옆 `models` 폴더를 자동 선택하므로 추가 다운로드·설치·변환 없이
   바로 사용할 수 있습니다. 처음 실행할 때 **모델 준비 / 복구**를 누를 필요가 없습니다.
3. **웹소설** 탭에서 작품 URL을 입력하고 **목차 확인**을 누릅니다.
   시작·마지막 화를 지정합니다. 마지막 화 `0`은 끝까지 받습니다.
4. 출력 파일을 지정하고 **번역 실행**을 누릅니다. 위치를 비웠다면 저장
   창이 열립니다. 자동 파일명을 켜면 작품 제목으로 저장합니다.
5. 작업 큐에서 본문 진행률·완료·오류를 확인합니다. 대기 작업은 순서를
   바꾸거나 삭제할 수 있습니다. 한글 경로를 사용할 수 있습니다.

`internal`은 내부 모델로 번역하고 `passthrough`는 일본어 원문을 저장합니다.
기존 GUI의 ezTrans/native 설정은 internal로 전환됩니다. 기존 설정 파일은
**저장**을 누르기 전까지 보존됩니다. 작업마다 추가 당시의 설정을 사용합니다.

## 교정 기억

**교정 기억** 탭에서 일본어 원문과 직접 고친 한국어를 입력하고 저장합니다.
같은 문장을 다시 번역할 때 해당 교정을 사용합니다. **용어 교정**에는
일본어 용어·기존 한국어 표현·바꿀 한국어를 입력합니다. 해당 일본어가
원문에 있을 때만 한국어 표현을 치환합니다. 목록에서 수정·삭제할 수 있습니다.

이는 작은 로컬 번역 메모리이며 모델 가중치를 재학습하지 않습니다.
자동 생성 결과는 학습하지 않습니다. 저장한 교정은 이후 시작하는 작업에
반영되며 **교정 기억 적용**을 끄면 반영하지 않습니다. 이전 TSV 보호 사전은
내부 모델에 사용하지 않습니다. 교정 기억 파일을 복사하면 백업할 수 있습니다.

## 모델·설정·오류

기본 교정 예문·고유명사 68개와 원문 조건이 있는 이름 교정 6개는 압축하여
실행 파일에 내장합니다. 새 교정 파일은 `corrections.json.zlib`이며 기존 JSON도
읽습니다. 사용자 수정·삭제는 보존됩니다. EHND 텍스트 사전은 교정 기억 탭에서
가져올 수 있고, ezTrans 전용 합성 토큰·정규식·제어 지시문은 적용하지 않습니다.

추가로 다운로드한 모델과 교정 기억은 `%LOCALAPPDATA%\SyousetuTranslate`에 보관합니다.
릴리즈에 포함된 모델은 실행 파일 옆 `models` 폴더를 우선 사용하고, 교정 기억은
사용자 데이터 폴더에 보관합니다. 설정에서 별도 모델 폴더·교정 파일을 지정할 수 있습니다.
**번역 추론은 오프라인**으로 동작합니다. 실시간 목차·본문 다운로드에는
해당 사이트 접속이 필요합니다. 번역 문장은 모델 다운로드 서버에 전송하지 않습니다.

64비트 Windows에서 INT8 가중치를 직접 읽고 작업자 사이에 공유합니다.
번역 작업에 약 1GB의 여유 메모리를 권장합니다. 다른 PC에서도 모델 폴더의
config.json·sentencepiece.bpe.model·vocab.json·model-int8.gguf를 ja-ko 하위에
복사하면 원본 다운로드 없이 사용할 수 있습니다. CPU 설정은 전체 연산 예산이며
작업자마다 그 수만큼 CPU를 추가 사용하는 방식이 아닙니다.

모델 누락·손상 오류는 **모델 준비 / 복구**로 해결합니다. 다운로드가 중단되어도
다시 준비하면 검증된 파일과 부분 다운로드를 재사용합니다. 번역에 실패하면 기존 출력 파일을
덮어쓰지 않습니다. 작업 로그에서 원인을 확인해 주세요.

복구 다운로드가 필요한 경우에도 완성된 INT8 약 354MB와 소형 설정·토크나이저만
받습니다(합계 약 360MB). 원본 1.34GB 다운로드나 PC에서의 변환은 수행하지 않습니다.

이 공개 경량 모델은 소설의 이름·속어·긴 문장에서 오역할 수 있습니다.
ezTrans와 같은 결과를 보장하지 않으며 교정 기억으로 선호 표현을 보완할 수 있습니다.
라이선스와 모델 출처는 `THIRD_PARTY_NOTICES.md` 및 `licenses` 폴더에 있습니다.

지원 사이트: Kakuyomu, Alphapolis, Syosetu, Syosetu18, Hameln, Novelup.
사이트 접근 제한이나 형식 변경은 작업 로그에 표시됩니다.

## HTTPS 인증서 오류

Windows 시스템의 신뢰된 인증서 저장소를 사용합니다. `UnknownIssuer`가
계속되면 Windows 업데이트와 보안 프로그램·사내 프록시의 루트 인증서
설치를 확인해 주세요. 필요한 경우 **설정 → 추가 CA 인증서 (PEM)** 에
관리자가 제공한 인증서 파일을 지정한 뒤 모델 준비를 다시 실행합니다.
CLI에서는 `--ca-bundle certificates.pem`을 사용할 수 있습니다.
인증서·호스트 이름 검증은 끄지 않습니다. 이미 받은 정상 모델 파일은 재사용합니다.
