# v0.3.6 이후 금지 표현 보완

이 변경은 2026-11-16 공개한 v0.3.6 이후의 소스 개선입니다. 공개 ZIP은
`00ce86c` 태그로 고정되어 있으며, 이 후속 변경 때문에 교체되지 않습니다.

실제 고정 모델에서 `飲んじゃだめ`가 “마시지 않아도 된다”로 번역되는 문제가
재현됐습니다. `てはだめ`로 바꾸는 기존 시험도 이 문제를 해결하지 못했습니다.
별도 시험에서 `飲んではいけない`는 “마시지 말아야 한다”로 번역됐습니다.
`入っちゃだめ`에는 같은 표현이 이중 부정을 남겨, 별도로 확인한 부정 부탁형을
사용했습니다. 알려진 여섯 동사와 확인된 종결 형태만 처리합니다.

- 완결된 일본어 대화 인용에만 적용하고 대상·시간·물체·질문 부호를 유지합니다.
- 허용, 의무, 금지의 부정, 표현 자체의 인용, 여러 문장과 과거·미확인 질문은
  임의로 바꾸지 않습니다. 예를 들어 `食べなきゃダメ`는 의무이며 금지가 아닙니다.
- 존댓말 금지를 반말 명령으로 출력한 경우 원문의 명시적인 말투에 맞춥니다.
- 사용자 교정·사전 우선순위, 전체 어휘, 신경망 가중치, 문단 순서와 스트리밍은 유지합니다.

[128문장 실제 비교](prohibition-review-results.json)는 교정 기억 없이, 같은 모델과
32개 문맥으로 v0.3.6 Linux 실행 파일과 수정 실행 파일을 각각 실행했습니다.
6문장이 바뀌고 나머지 122문장은 동일했습니다. 출력 변경 수는 정확도 점수가 아닙니다.

| 원문 | v0.3.6 | 수정 결과 |
| --- | --- | --- |
| `その水は飲んじゃだめだよ。` | 그 물을 마시지 않아도 되겠지? | 그 물을 마시지 말아야 해. |
| `まだ中に入っちゃだめだよ。` | 그럼 아직 안 들어가지 말아야? | 그럼 아직 안에 들어가지 마. |
| `もう食べちゃだめなの？` | 너 이제 먹지 않아? | 더 이상 먹어도 안 돼? |
| `まだ中に入っちゃダメです。` | 별도 후보에서 반말 명령이 확인됨 | 그럼 아직 안에 들어가지 마세요. |

부정이 재차 붙은 `飲んじゃダメではない` 등에는 기본 모델의 오역이 남습니다.
처리 범위를 넓힌다는 이유로 허용을 금지로 뒤집지 않으며, 이 결과를 모든 문맥의
오역 해결이나 인간 수준의 번역 품질로 표시하지 않습니다.

검증: 전체 production/legacy 회귀, Clippy `-D warnings`, 실제 모델의 기존 대화와
새 금지 의미 테스트, 순차/병렬 결과 일치 및 256개 문맥 재사용 테스트를 통과했습니다.
후속 성능 시험은 번역 의미의 이 변경과 계산 재사용의 효과를 구분해 측정합니다.
