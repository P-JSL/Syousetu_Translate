# Syousetu Translate

**일본어 웹소설을 한국어로 번역하고, 회차 순서대로 TXT 파일에 저장하는 Rust 기반 프로그램입니다.**

작품 URL 입력 → 목차 확인 → 회차·저장 위치 선택 → 번역 실행까지 Windows GUI에서 처리할 수 있습니다. 기본 번역 엔진은 CPU에서 실행되는 **SMaLL-100 INT8**이며, 일본어를 영어 경유 없이 한국어로 직접 번역합니다.

- **현재 릴리스:** [v0.3.5](https://github.com/P-JSL/Syousetu_Translate/releases/tag/v0.3.5)
- **최신 버전:** [GitHub Releases](https://github.com/P-JSL/Syousetu_Translate/releases/latest)
- **지원:** Windows 10/11 x64 휴대용 배포판 · Rust CLI 및 Linux GUI 소스 빌드
- **필요하지 않은 것:** Java/JRE, Python, GPU, ezTrans XP, 외부 유료 번역 API

> 번역 모델의 추론은 로컬에서 오프라인으로 처리됩니다. 웹소설의 목차와 본문을 직접 가져오는 작업에는 인터넷 연결이 필요합니다.

## 1. 다운로드 및 실행

### Windows 10/11 (64비트)

1. [최신 릴리스](https://github.com/P-JSL/Syousetu_Translate/releases/latest)를 엽니다.
2. `SyousetuTranslate-Web-*-Windows-x64.zip` 파일을 다운로드합니다. v0.3.5의 정확한 파일명은 `SyousetuTranslate-Web-v0.3.5-Windows-x64.zip`입니다.
3. ZIP **전체를 원하는 폴더에 압축 해제**합니다. ZIP 내부에서 BAT만 실행하지 마세요.
4. **`웹소설 번역기.bat`**을 더블클릭합니다.
5. 프로그램 상단의 **웹소설**, **설정**, **교정 기억** 탭을 사용합니다.

배포 패키지에는 GUI와 CLI 실행 파일, SMaLL-100 INT8 모델 및 설정/토크나이저가 포함됩니다. 실행 파일 옆의 `models` 디렉터리 구조를 유지해야 합니다. 정상적인 패키지라면 첫 실행 시 별도 모델 다운로드나 변환 작업이 필요하지 않습니다.

배포판에 포함되는 주요 파일:

```text
웹소설 번역기.bat
syousetu-gui.exe          # Windows GUI
syousetu-translate.exe    # CLI / GUI 작업 실행
models/
  ja-ko/
    model-int8.gguf
    config.json
    sentencepiece.bpe.model
    vocab.json
```

**권장 여유 메모리:** 2GB 이상. 작업자 수와 본문 길이에 따라 메모리 사용량이 달라집니다. 모델은 CPU에서 동작하며 별도 GPU가 필요하지 않습니다.

### 설치 상태 확인

GUI의 **웹소설** 탭에 `SMaLL-100 INT8 준비됨 · 번역은 오프라인`이 표시되면 모델이 준비된 상태입니다. 모델이 없거나 손상된 경우에는 **모델 준비 / 복구**를 실행하세요. 이 기능은 사전 준비된 INT8 모델 파일을 검증하고 필요한 파일을 다시 받습니다.

## 2. 웹소설 번역 방법

### ① 작품 주소 입력 및 목차 확인

**웹소설** 탭의 **작품 URL**에 지원 사이트의 작품 주소를 입력하고 **목차 확인**을 누릅니다. 정상적으로 조회되면 화면에 **작품 제목 · 전체 회차 수**가 표시되고 마지막 화 입력값이 조회된 회차 수로 갱신됩니다.

지원 사이트:

| 사이트 | 주소 |
| --- | --- |
| Kakuyomu | https://kakuyomu.jp |
| Alphapolis | https://www.alphapolis.co.jp |
| 소설가가 되자 (Syosetu) | https://syosetu.com |
| Syosetu18 | https://novel18.syosetu.com |
| Hameln | https://syosetu.org |
| Novelup | https://novelup.plus |

사이트에서 접근을 제한하거나 HTML 구조가 변경된 경우 목차/본문을 가져오지 못할 수 있습니다. 로그인, CAPTCHA, 유료 콘텐츠 및 연령 인증을 우회하지 않습니다.

### ② 번역 회차 지정

| 입력 항목 | 의미 | 예시 |
| --- | --- | --- |
| **시작 화** | 번역을 시작할 회차 번호 | `1` |
| **마지막 화** | 번역을 끝낼 회차 번호 | `20` |
| **마지막 화 = 0** | 조회 가능한 마지막 회차까지 처리 | `0` |

예를 들어 **시작 화 5 / 마지막 화 10**은 5~10화를, **시작 화 5 / 마지막 화 0**은 5화부터 마지막 회차까지 처리합니다. 마지막 화가 시작 화보다 작으면 작업을 시작하지 않습니다.

### ③ 저장 위치 및 파일명 지정

- **출력 파일:** 저장할 TXT 파일의 전체 경로를 직접 입력할 수 있습니다.
- **저장 위치 선택:** 파일 저장 대화상자에서 경로와 파일명을 지정합니다.
- **파일명 자동 생성 (출력 파일을 비운 경우):** 출력 파일 입력이 비어 있으면 작품 제목을 사용해 기본 다운로드 폴더에 자동 저장합니다.
- 자동 생성이 꺼져 있고 출력 파일도 비어 있다면 저장 위치 선택 대화상자가 열립니다.

**다른 PC에서 주의:** 현재 소스 코드의 Windows 기본 다운로드 폴더는 특정 사용자 경로로 설정되어 있습니다. 처음 사용할 때 **설정 → 다운로드 기본 폴더**를 실제 사용 가능한 폴더로 변경하는 것을 권장합니다.

### ④ 번역 실행 및 진행 확인

**번역 실행**을 누르면 작업 큐에 번역 작업이 추가됩니다. 작업 큐에서 다음 항목을 확인할 수 있습니다.

- **대기 / 진행 / 완료 / 실패** 상태
- 선택한 작업의 진행률과 작업 로그
- **대기 작업 위로 / 대기 작업 아래로**를 통한 순서 변경
- **목록에서 삭제 (진행 작업 제외)**: 진행 중인 작업은 이 버튼으로 삭제하지 않습니다.

새로 추가하는 작업에는 해당 시점의 설정이 적용됩니다. 이후 설정을 저장해도 **이미 추가된 작업의 설정은 자동 변경되지 않습니다.**

### ⑤ TXT 파일 및 백업

번역 결과는 지정한 `.txt` 파일에 **완료된 순서대로 실시간 기록**됩니다. 파일이 완성되기 전에도 저장된 부분을 확인할 수 있습니다.

- 작업 중단·실패 시 이미 정상 기록된 내용은 남습니다.
- 기존 출력 파일을 덮어쓰는 작업은 기존 내용을 `.backup`에 보존할 수 있습니다.
- 작업 성공 시 해당 작업의 백업은 정리됩니다.
- 실패 후 백업이 남았다면 **내용을 먼저 확인**한 뒤 같은 출력 파일로 재실행하세요.

## 3. 설정 항목 안내

상단 **설정** 탭에서 옵션을 변경할 수 있습니다. **저장** 버튼으로 설정 파일에 기록하거나 **불러오기**로 다시 읽을 수 있습니다.

| 설정 | 설명 |
| --- | --- |
| **번역기: internal** | 기본 SMaLL-100 INT8 일→한 번역 |
| **번역기: passthrough** | 일본어 원문을 그대로 저장하는 테스트 모드 (번역 아님) |
| **본문 처리 방식: 자동 성능 확인** | 첫 본문 묶음의 출력 일치 여부와 처리 시간을 확인해 단일/병렬 중 선택 |
| **본문 처리 방식: 단일 / 병렬** | 사용자가 처리 방식을 명시적으로 선택 |
| **번역 작업자 수** | `-1` = 기본 논리 작업자 32개. GUI에서 최대 256개까지 선택 가능 |
| **일본어 동시 출력** | 번역 결과와 함께 일본어 원문을 기록 |
| **후리가나 포함** | 원문의 후리가나 포함 여부 지정 |
| **작가 코멘트 포함** | 지원하는 사이트의 작가 코멘트 포함 여부 지정 |
| **다운로드 기본 폴더** | 자동 파일명 사용 시 저장할 기본 디렉터리 |
| **모델 폴더** | 기본 모델 탐색 위치 대신 사용할 로컬 경로 |
| **교정 기억 적용** | 저장한 사용자 교정을 번역에 반영할지 지정 |
| **화 제목 / 번호 형식** | 각 화 제목과 번호의 TXT 출력 형식 설정 |
| **다운로드 간격 / 재시도 횟수** | 웹 요청 사이의 간격 및 오류 시 재시도 설정 |
| **추가 CA 인증서** | 사내망 등에서 필요한 추가 PEM 인증서 지정 |

**작업자 수를 크게 설정해도 성능이 비례해서 증가하지는 않습니다.** 모델 가중치는 공유되지만 배치 크기가 커지면 메모리가 더 필요할 수 있습니다. 먼저 기본값과 자동 성능 확인을 사용하는 것을 권장합니다.

설정 파일의 기본 경로는 프로그램 실행 폴더 기준 `config/config.properties`입니다.

## 4. 교정 기억 사용법

**교정 기억** 탭에서는 사용자가 직접 검토하고 수정한 번역만 로컬에 저장합니다.

### 문장 교정

1. **문장 교정**을 선택합니다.
2. 일본어 원문과 원하는 한국어 번역을 입력합니다.
3. **교정 기억 저장**을 누릅니다.

예시:

| 일본어 원문 | 교정한 한국어 |
| --- | --- |
| `私は学生です。` | `저는 학생입니다.` |

저장된 문장 교정은 일치하는 원문 단위에 적용되며, 모델이 생성한 번역보다 우선합니다.

### 용어 교정

**용어 교정**은 일본어 원문과 기존 번역 표현을 함께 확인한 후 바꿉니다.

| 항목 | 예시 |
| --- | --- |
| 일본어 원문 용어 | `アリス` |
| 기존 한국어 표현 | `앨리스` |
| 바꿀 한국어 표현 | `아리스` |

일본어 원문에 해당 용어가 있을 때만 지정한 한국어 표현을 교체합니다. 교정 목록에서는 등록 항목의 수정·삭제와 **목록 새로고침**이 가능합니다. 사용자 지정 교정은 **이후 시작하는 번역 작업**에 적용됩니다.

교정 데이터는 사용자 데이터 폴더의 `corrections.json.zlib` 등에 보관되며, 이전 JSON 프로필도 지원합니다. 이는 **번역 메모리**이지 모델 가중치를 재학습하는 기능이 아닙니다. 자동 생성 번역을 임의로 학습 데이터로 수집하지 않습니다.

## 5. 문제 해결

| 현상 | 확인 및 조치 |
| --- | --- |
| BAT 실행 시 GUI를 찾을 수 없음 | ZIP을 완전히 풀었는지, `syousetu-gui.exe`가 BAT와 같은 폴더에 있는지 확인 |
| 모델이 준비되지 않았다고 표시됨 | `models` 폴더 구조를 확인하고 **모델 준비 / 복구** 실행 |
| 작품 목차 조회 실패 | 작품 URL, 인터넷 연결, 사이트 접근 가능 여부 확인. **작업 큐 → 해당 작업 로그** 확인 |
| 번역 실행 후 실패 | 작업 로그에서 오류 원인을 확인하고 기존 TXT 및 `.backup` 내용 보존 |
| 저장할 폴더에 파일이 보이지 않음 | **설정 → 다운로드 기본 폴더** 또는 **출력 파일**의 실제 경로 확인 |
| `UnknownIssuer` 등 HTTPS 인증서 오류 | Windows 신뢰 인증서 또는 사내 프록시/보안 프로그램 CA 확인. 필요한 경우 **추가 CA 인증서 (PEM)** 지정 |
| 속도가 느리거나 메모리가 부족함 | **본문 처리 방식: 자동 성능 확인** 및 작업자 수 32 등으로 비교. 작업자를 무조건 늘리지 않기 |

인증서·호스트명 검증을 끄지 않으며, 모델 복구 파일도 무결성을 확인합니다.

## 6. 개발자용: 빌드 및 CLI

개발에는 **Rust와 Cargo**가 필요합니다. 소스 빌드는 배포 ZIP과 달리 번역 모델을 별도로 준비해야 할 수 있습니다.

### 빌드 및 테스트

```bash
# 기본 CLI 릴리스 빌드
cargo build --locked --release

# GUI와 CLI를 함께 빌드
cargo build --locked --release --features gui --bins

# 모델 준비 및 검증 (소스 빌드 시 필요할 수 있음)
cargo run --locked --release -- models --prepare
cargo run --locked --release -- models --verify

# 테스트 및 Clippy
cargo test --locked --all-targets
cargo clippy --locked --all-targets
```

GUI 실행 파일: `target/release/syousetu-gui` (Windows는 `.exe`). GUI와 CLI는 동일한 디렉터리에 두어야 합니다. Linux GUI는 X11/OpenGL 실행 환경이 필요하며 CLI에는 그래픽 환경이 필요하지 않습니다.

### CLI 사용 예시

```bash
# 지원 작품의 목차/회차 정보 확인
cargo run --locked --release -- inspect --url "https://kakuyomu.jp/works/2912051603596422650"

# 1~2화 번역 및 출력 파일 지정
cargo run --locked --release -- download --url "https://kakuyomu.jp/works/2912051603596422650" --start 1 --end 2 --out novel.txt

# 일본어 원문을 포함하고 작업자 16개로 처리
cargo run --locked --release -- download --url "https://kakuyomu.jp/works/2912051603596422650" --start 1 --end 2 --out bilingual.txt --japanese --jobs 16

# 로컬 TXT 번역
cargo run --locked --release -- file --input original.txt --out translated.txt

# 한 문장 번역
cargo run --locked --release -- translate --text "私は学生です。"

# 문장 교정 등록
cargo run --locked --release -- memory --learn --source "私は学生です。" --corrected "저는 학생입니다."

# 문장 교정 삭제
cargo run --locked --release -- memory --forget --source "私は学生です。"
```

자주 사용하는 옵션:

| 옵션 | 설명 |
| --- | --- |
| `--start N`, `--end N` | 시작·종료 회차 (CLI에서 `--end` 생략 시 마지막 회차까지) |
| `--out FILE` | 결과 TXT 파일 지정 |
| `--output-dir DIR`, `--auto-output` | 자동 파일명으로 저장할 폴더 또는 자동 저장 지정 |
| `--japanese`, `--no-japanese` | 일본어 원문 동시 출력 여부 |
| `--jobs 1..256` | 논리적 번역 작업 용량 (기본 32) |
| `--parallel-mode auto\|serial\|parallel` | 처리 방식 선택 |
| `--model-dir PATH` | 모델 폴더 지정 |
| `--memory-path PATH`, `--no-learning` | 교정 파일 경로 및 교정 적용 끄기 |
| `--cache-html-dir DIR` | 조회한 작품 정보와 각 화 HTML 로컬 보관 |
| `--delay-ms N`, `--retry N` | 다운로드 간격 및 재시도 횟수 |
| `--ca-bundle FILE` | 추가 신뢰 CA 인증서 지정 |

전체 명령은 `cargo run -- --help`로 확인할 수 있습니다. `--out`과 `--output-dir`는 함께 지정할 수 없습니다. 일부 호환 기능은 `legacy` 빌드 기능이 필요하며 기본 배포판에는 포함되지 않습니다.

## 7. 구조와 한계

- **사이트 파서:** Kakuyomu, Alphapolis, Syosetu, Syosetu18, Hameln, Novelup의 작품 및 회차 HTML을 처리합니다.
- **기본 번역:** SMaLL-100 INT8 모델을 Rust/Candle 기반으로 실행합니다. 모델과 번역 문장을 외부 번역 API에 보내지 않습니다.
- **교정·표현 처리:** 내장된 표제어·검토된 교정 규칙 및 사용자 교정 기억을 적용합니다.
- **병렬 처리:** 공유 모델 가중치와 분리된 번역 상태를 사용합니다. 출력 순서를 유지하지만 네트워크 시간 및 신경망 추론을 포함한 전체 수행 시간이 O(n)이라고 보장하지 않습니다.
- **품질 한계:** 고유명사, 속어, 등장인물 간 관계, 장문 문맥 등을 잘못 번역할 수 있습니다. 문학 번역 수준이나 ezTrans 결과 동일성을 보장하지 않습니다.
- **호환 범위:** 원본 ezTrans 상용 번역 엔진 자체는 Rust로 완전히 이식되지 않았습니다. 상용 DLL/사전의 별도 사용과 실험적 호환 기능은 일반 사용자용 내부 번역 엔진과 구분됩니다.
- **검증 범위:** 지원 사이트의 모든 작품·페이지 변형 및 모든 Windows PC에서의 정상 실행이 전수 검증된 것은 아닙니다.
